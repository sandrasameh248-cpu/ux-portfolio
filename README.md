# UI/UX Portfolio

A single-page UI/UX portfolio with an interactive mobile app prototype (Dafter study planner), process, case study and design system.

## Run
Open `index.html` in a browser. No build step.

## Customize
- Replace "Your Name" and the contact section in `index.html`.
- Swap the case study text with your own project.
- Colors live in the `:root` variables at the top of the file; dark mode is automatic.

## Publish on GitHub Pages
1. Create a repository and upload these files.
2. Go to Settings → Pages, choose the `main` branch, and save.

How I work

The same four steps on every project, so decisions are always backed by users.

  1. ResearchInterviews and surveys to find what slows people down.
  2. DefinePersonas, user flows and a clear problem statement.
  3. DesignWireframes, then a tested interactive prototype.
  4. TestUsability sessions, fixes, and a handoff to developers.

Dafter: a study planner for university students

A mobile app that turns a messy list of deadlines into a short plan for today.

Problem

Students tracked deadlines across chats, notebooks and calendars, and missed tasks because nothing showed what to do first.

Solution

One screen with only today’s tasks, a three-field add flow, and a progress view that rewards finishing instead of planning.

Result

12 → 4

Average taps to add a task, measured in a test with 8 participants.
